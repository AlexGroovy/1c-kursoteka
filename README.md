# 1С-Курсотека

Каталог дистанционных курсов по 1С: онлайн-занятия, WEB-курсы и видеокурсы с разных площадок. Курсы сгруппированы по теме, чтобы сравнить формат, стоимость и продолжительность.

Каталог помогает выбрать обучение по теме, а не обходить каждую площадку отдельно. В одной таблице видны официальные учебные центры, авторские программы и узкие практические занятия.

## Участие

Нашли курс, которого здесь нет? Откройте новое issue с ссылкой на карточку курса. Каталог обновляется раз в неделю.
